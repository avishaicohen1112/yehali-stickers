# תיקון — גיליונות האויבים C2 (חובה לקרוא לפני שממשיכים)

**מה השתבש:** ב־C2-02 יצאה דמות אחרת לגמרי (זחל במקום ה"קליפה" המקורית), והרקע יצא אפור. זה אסור.

## כללים לכל גיליון C2 (וגם לכל דמות קיימת בהמשך: הגיבור, הדמויות, הבוסים)
1. **אל תמציא עיצוב חדש.** כל אויב כבר קיים — בגיליון המקורי שלו (C-A עד C-E מצורפים להודעה; את C-F תיצור בשלב ה' ותשתמש בו כ־reference ל־C2-19 עד C2-22). **תעתיק אותו בדיוק** מהשורה שלו: אותה צורת גוף, אותם צבעים, אותם פרופורציות, אותו פרצוף, אותם פרטים. רק התנוחות משתנות.
2. **בכל יצירה — צרף מחדש** את הגיליון המקורי של האויב (אחד מהמצורפים) ואת A00, ותכתוב בפרומפט: "Use the attached sheet ONLY as exact character reference: same design, same colors, same proportions. Do not redesign."
3. **אותו סגנון ציור** כמו הגיליון המקורי ו־A00 — אותו מכחול, אותה תאורה, אותם קווי מתאר כהים.
4. **רקע שקוף אמיתי.** אם לא מצליח — ירוק טהור #00FF00 אחיד. **אף פעם לא אפור או כהה.**
5. **תתחיל מחדש מ־C2-01** (גם C2-01 וגם C2-02 שכבר יצרת — מחדש).

## מי זה מי (שורה בגיליון המקורי + תיאור)
- **C2-01 = זחל שעווה (Wickling)** — השורה ה־1 בגיליון **C-A**. זחל קטן מפולח משעווה ענברית, עיניים שחורות קטנות, שני פתילים קטנים על הגב.
- **C2-02 = קליפה (Husk)** — השורה ה־2 בגיליון **C-A**. יצור נר נמס בגובה אדם, גוף שעווה צונח ועקום, פנים שקועות עם שתי עיניים גחלת כתומות זוהרות, זרועות ארוכות נוזלות.
- **C2-03 = זבוב גחלת (Emberfly)** — השורה ה־3 בגיליון **C-A**. חרק קטן עם בטן גחלת כתומה זוהרת וגוף שחור.
- **C2-04 = עשון (Mothling)** — השורה ה־4 בגיליון **C-A**. עש לבן פרוותי, מחושים נוצתיים, כתמי עין כחולים זוהרים על הכנפיים.
- **C2-05 = כובען נבגים (Sporecap)** — השורה ה־1 בגיליון **C-B**. פטרייה מהלכת, כובע טורקיז עם נקודות זוהרות, רגל לבנה עם פרצוף קטן.
- **C2-06 = מדוזת פעמון (Bell-Jelly)** — השורה ה־2 בגיליון **C-B**. מדוזה שקופה־כחלחלה זוהרת עם ליבה בהירה.
- **C2-07 = נזיר טבוע (Acolyte)** — השורה ה־3 בגיליון **C-B**. נזיר בגלימה רטובה כהה, מסכת עצם בברדס, מחזיק פנס על מקל ומגל חלוד.
- **C2-08 = זקיף זכוכית (Sentinel)** — השורה ה־4 בגיליון **C-B**. אביר עשוי גביש סגול־שקוף עם ליבה זוהרת.
- **C2-09 = כנף רסיס (Shardwing)** — השורה ה־1 בגיליון **C-C**. עטלף־עש מזכוכית סגולה.
- **C2-10 = רוח אפר (Ash Wraith)** — השורה ה־2 בגיליון **C-C**. רוח רפאים גבוהה בגלימת עשן קרועה, ברדס עם שתי עיני גחלת אדומות, טפרי עצם.
- **C2-11 = סרטן אפר** — השורה ה־3 בגיליון **C-C**. סרטן שחור עם שריון סדוק ובוער מבפנים.
- **C2-12 = שחף אפר** — השורה ה־4 בגיליון **C-C**. עוף ים אפור מעושן עם עיניים זוהרות.
- **C2-13 = גץ (Cinder)** — השורה ה־1 בגיליון **C-D**. רוח קטנה של גחלת עם זנב להבה (בלי פרצוף).
- **C2-14 = מלח רפאים** — השורה ה־2 בגיליון **C-D**. מלח שלד־רפאים סגלגל עם מגל־סכין וכובע קפטן קרוע.
- **C2-15 = עגורן נייר** — השורה ה־3 בגיליון **C-D**. עגור אוריגמי לבן־שנהב.
- **C2-16 = חייל נייר** — השורה ה־4 בגיליון **C-D**. חייל מקופל מנייר עם חנית נייר.
- **C2-17 = גלגל שיניים** — השורה ה־1 בגיליון **C-E**. גלגל שיניים מפליז עם עין אחת זוהרת במרכז.
- **C2-18 = רוח שעון** — השורה ה־2 בגיליון **C-E**. כדור זוהר עם מחוגים מסתובבים בתוכו ושובל אור.
- **C2-19 = רוח סערה** — השורה ה־1 בגיליון **C-F**. ישות של אוויר ואבק מסתחרר עם מסכת עצם ושתי עיניים כחולות־לבנות זוהרות; התקפה = נשיפה קדימה.
- **C2-20 = עש רוח** — השורה ה־2 בגיליון **C-F**. עש אפור עם כנפיים קרועות שגולש על הרוח, עיני גחלת; התקפה = צלילה.
- **C2-21 = זחל עוגן** — השורה ה־3 בגיליון **C-F**. יצור קטן וכבד שנאחז ברצפה בטפרים, שריון צפחה, עין גחלת אחת.
- **C2-22 = מטיל רסיסים** — השורה ה־4 בגיליון **C-F**. יצור דמוי עץ קטן ויבש שזורק רסיסי קליפה; עיניים כתומות.

## אחרי האויבים
- **A04, A05 (הגיבור)**: אצרף לך את A01 ואת A02. אותו כלל — העתק מדויק של הגיבור, רק תנוחות חדשות.
- **B08, B09 ובוסים T**: דמויות חדשות — כאן מותר לעצב, אבל באותו סגנון בדיוק כמו A00.
