# הנדאוף — "הפתיל האחרון" (The Last Wick)

אתה ממשיך פרויקט קיים. קרא את הקובץ הזה ואז את `last-wick/README.md` ו־`last-wick/ART_BRIEF.md`.

## מה זה
מטרויידבניה דו־ממדית בסגנון Hollow Knight, ב־JS וניל + Canvas 2D (בלי build, נפתח גם מ־file://), עברית.
- ריפו: `avishaicohen1112/yehali-stickers`, **ענף `ccr-46d5e42a-c9dnse`**, תיקייה `last-wick/` (שאר הריפו = משחק ישן, לא לגעת).
- מבנה: `js/` (main, player, enemies, bosses, objects, world, render, scenery, puppet, fx, ui, text, audio, input, assets, data.js מג'ונרט), `tools/` (פייתון), `assets/`.
- נתונים: `tools/world.py` מגדיר את כל החדרים (ASCII מחוצב: `#` מוצק, `=` פלטפורמה חד־כיוונית, `^` קוצים, `~` מים/ים אש קטלני, `x` שער צל). אחרי כל שינוי: `python3 tools/build_data.py` (יוצר `js/data.js`).

## מצב נוכחי
- 3 עולמות, 44 חדרים, 13 בוסים, 18 אויבים, 3 יכולות שער לכל עולם (dash, djump, wall · glide, shadow), פורטלים בין עולמות, מפה לכל עולם, חנות, מזבחות שמירה, NPC, מוזיקה פרוצדורלית לכל אזור (`js/audio.js`).
  - לומנהולד: crypts/gardens/nave/spire/hearth · בוסים knight, moth, angler, vesper, extinguisher + אופציונליים choir, colossus.
  - ים הגחלים: shore/galleon/lighthouse · leviathan, captain, keeper. עולם החלום: paper/clock/core · paperking, clockmaker, firstflame (סוף).
- כל הלוגיקה עובדת ונבדקה בבוטים (בלי שגיאות, אין היתקעויות).
- **הגרפיקה כרגע זמנית**: רינדורים מבלנדר (`tools/*3d.py`) לעולם 1, ובלוקים/כתמים בעולמות 2–3. המשתמש **לא אוהב** את האמנות התלת־ממדית — הוחלט שהאמנות תגיע מצ'אט GPT (מודל תמונות). **אסור לייצר אמנות בעצמך יותר** — רק לתאר, לבנות מנועים ולשלב.

## זרימת האמנות (הדבר העיקרי עכשיו)
1. המשתמש פתח בצ'אט GPT פרויקט עם `last-wick/ART_BRIEF.md` (המגילה: ~130 תמונות, לפי IDs: A00 סגנון, A01 גיבור, A02–A03 גיליונות 4×4 של הגיבור, B דמויות, C גיליונות אויבים 4×4 (שורה=אויב, 4 תנוחות), D בוסים (איור + גיליון 4×2 + דף חלקים), E–P אזורים (רקע רחוק, צלליות, אמצע, קדמי, אלמנטים, ערכת קרקע, מרקם, אביזרים), J כללי).
2. המשתמש שולח לך את התמונות **במייל לעצמו עם נושא "לקלוד"** כקבצים מצורפים. אתה מושך עם Gmail MCP: `search_threads` ← `get_thread` ← `download_gmail_attachment`. (גוגל דוקס חסום מהסביבה — קישורי דוקס לא עובדים.)
3. שילוב:
   - `tools/ingest.py` — מסיר רקע (שקוף/ירוק/לבן, עם despill), מפצל גיליון לרכיבים ומסדר לפי סדר קריאה. `sheet` / `single` / `layer --tile`.
   - **`tools/posesheet.py`** (בנוי ונבדק) — גיליון תנוחות → אטלס v2 עם **עוגן נפרד לכל פריים**. מונע ע"י "מתכון" ב־`tools/sheets/<atlas>.json` (מקור, רשת, שם לכל תא, קנה מידה לפי פריים־ייחוס בגובה px במשחק, אנימציות, תיקוני עוגן ידניים `override`). הרצה: `python3 tools/posesheet.py --all --debug <dir>` ואז `python3 tools/build_data.py`. מקור חסר ← מדלג ולא דורס את האטלס הישן.
     - עוגן: y = קו הרגליים (השורה המוצקה הנמוכה; מחט/צעיף דקים לא נספרים), x = מרכז "ליבת" הגוף (אלפא מכורסם). מעופפים/מרחפים: `"anchorY":"center"` (מרכז הגוף קבוע). קצה הפתיל (`tip`) לכל פריים לגיבור.
     - `--debug DIR` מייצר `<atlas>_anchors.png`: כל פריים מיושר על העוגן + שורת "בצל" לכל אנימציה — **לבדוק בעין לפני commit**.
     - חלוקה לתאים: קווי חיתוך נצמדים לפס הריק ביותר; חלק שגולש לתא שכן נשאר אצל בעליו (רוב השטח), ואם מתחלק — נחתך בקו הרשת.
     - פורמט v2: `f=[x,y,w,h]`, `o=[ox,oy]` לפריים, `speed` (ריצה לפי מהירות: `frame = floor(runPhase*speed)`), `v:2`. `G.Sprite.draw/point` תומכים בשני הפורמטים.
     - מתכונים קיימים: `wick` (A02+A03; שמות התאים לפי סדר השורות בתדריך), וכל 18 האויבים `e_*` (C-A..C-E, שורה=אויב: rest, move1, move2, attack).
     - שגיאה: מקורות נשמרים ב־`last-wick/art_src/<ID>.<ext>` (A02.png, C-A.png...). בגיבור: אנימציה שחסרה באטלס נופלת לקרובה (glide→fall, slashup→slash, death→hurt...).
     - הגיבור: נשימה עדינה (sy) ב־idle לאטלס v2, `glide`/`djump` מחוברים למצבי הפיזיקה.
     - גם מתכונים לבוסים `b_*` (גיליון 4×2: idle1 idle2 windup attack follow special hurt dead → האנימציות שכל בוס משתמש בהן בקוד). `tools/sheet2atlas.py` = כינוי ל־posesheet.
   - **`tools/area.py <אות>`** (בנוי ונבדק על תמונות דמה): X1..X8 של אזור → `assets/scn/<area>/` (far/sil/mid/front + אלמנטים מונפשים לפי סוג: hang/float/drift/spin/pendulum/wave), רשומה ב־`assets/scenes.json`, ערכת קרקע `assets/art/<area>/` (X6 נחתך ל־4 רצועות לפי פסים ריקים), מרקם `rock.png` (ריצוף דו־כיווני), אביזרים `assets/props/<area>_*.webp` + `sets.json`. `--rooms` מריץ גם `terrain2d.py` לחדרי האזור ו־`place_props.py`. שמות האלמנטים/אביזרים לכל אזור בטבלת `AREAS` בראש הקובץ. `--list` להצגה.
   - **אזהרה**: האביזרים התלת־ממדיים הישנים הוסרו בכוונה מהחדרים. `place_props.py` שונה כך שהוא מציב **רק** אביזרים מצוירים (`sets.json`) ולא נוגע באזורים אחרים — אל תחזיר את SETS הישנים.
   - `terrain2d.py` כבר לא תלוי בבלנדר (פונקציית `shape` הועתקה אליו).
   - שמות קבצים ב־`art_src/`: ר' `art_src/README.md`.
   - `tools/rigtool.py` + `js/puppet.js` — ריג חלקים (cutout) עם קפיצים לבד/צעיף ועיוות רשת (chain). לבוסים: אפשר גם לחתוך חלקים מאיור מלא.
   - `js/scenery.js` — רקעים בשכבות (`assets/scenes.json` → `window.SCENES`): שכבות עם parallax, tile, ערפל נע, קרני אור, אלמנטים מונפשים (sway/bob/flicker/chain), ושכבות קדמיות (`front:true`).
   - `tools/terrain2d.py` — צובע קרקע לכל חדר מערכת קרקע: `assets/art/<area>/rock.png, trim_top.png, trim_bottom.png, plat.png, spikes.png` (+ `kit.json`). להריץ לכל החדרים כשהערכה מגיעה.
   - `tools/place_props.py` — מיקום אביזרים אוטומטי; `assets/props/manifest.json`.
   - אטלסים: `assets/sprites/<name>.webp/.json` → `build_data.py` אוסף ל־`window.ATLAS`. אויבים `e_<kind>`, בוסים `b_<kind>`, NPC `n_<id>`, גיבור `wick`.

## כללים
- לדבר עם המשתמש בעברית, קצר וברור; הוא לא טכני. לעדכן אותו כל כמה דקות.
- commit + push לענף אחרי כל שלב (hook דורש). לא PR בלי בקשה.
- הבא בתור: לשלב כל מנה של תמונות שמגיעה (בסדר: A00–A03 גיבור, אחר כך עולם 1). עד 2026-11-23 הגיע רק מייל עם קובץ טקסט (שיטת VESPER) — אין עדיין תמונות במייל. המשתמש הראה צילומי מסך של A00 ו־A01 (מעולים, אהב אותם); ביקשנו ממנו לשלוח קבצים מקוריים.
- הערות שנשלחו ל־GPT: אור קצה קר סביב הגלימה, סימן סכנה זוהר לכל אויב, ניגודיות גבוהה+קו מתאר לדברים שמשחקים בהם / רקעים רכים ודהויים, פחות פרטים קטנטנים על דמויות.
- דרוש: `pip install opencv-python-headless` (cv2) בסשן חדש.

## איפה אנחנו עומדים ברגע זה (עדכון אחרון)
- המשתמש שלח את `ART_BRIEF.md` לפרויקט חדש בצ'אט GPT, וצ'אט GPT **מייצר עכשיו** את התמונות לפי הסדר (A00, A01, A02, ...).
- **אנחנו מחכים לתמונות.** הן יגיעו במייל לעצמו של המשתמש, נושא "לקלוד", כקבצים מצורפים (ייתכן כמה מיילים).
- **כשמגיעה מנה**: (1) למשוך את המיילים, (2) להסתכל על כל תמונה (Read) ולזהות את ה־ID, (3) לשמור ב־`art_src/<ID>.png`, (4) `ingest.py` / `posesheet.py` (גיליונות תנוחות, מתכונים ב־`tools/sheets/`) / `rigtool.py` לפי הסוג, (5) לחבר למשחק (אטלס `wick`, `e_*`, `b_*`, `n_*`, סצנות ב־`assets/scenes.json`, ערכות קרקע ב־`assets/art/<area>/` + `terrain2d.py`), (6) `build_data.py`, (7) צילום מסך במשחק ולבדוק בעין, (8) commit+push, (9) לדווח למשתמש בקצרה ולצרף צילום מסך.
- אם תמונה יצאה גרועה (דמות שונה, רקע לא נקי, חפיפה בין תאים) — לכתוב למשתמש הודעת תיקון קצרה ומדויקת שיעביר לצ'אט GPT, עם ה־ID.
