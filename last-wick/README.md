# הפתיל האחרון — The Last Wick

משחק מטרויידבניה בסגנון Hollow Knight, בדפדפן. JS/HTML/CSS וניל, בלי build step, בלי ספריות.
אפשר לפתוח את `index.html` ישירות (דאבל־קליק) או דרך GitHub Pages.

## הסיפור
השלהבת הגדולה של לומנהולד כבתה. ארבעה שומרים קרעו ממנה ארבע גחלים. אתה — פתיל קטן אחרון —
יוצא להחזיר אותן אל האח הכבויה שבראש הצריח, שם מחכה **המכבה**.

## עולם
5 אזורים, 20 חדרים מחוברים, 5 בוסים:

| אזור | בוס | פרס |
|---|---|---|
| מערות השעווה | אביר החֵלֶב | זינוק הגחלת (Dash) |
| גני העש | אם העש | כנפי עש (קפיצה כפולה) |
| הקתדרלה הטבועה | הדייג השקוע | טפרי שעווה (קפיצת קיר) |
| צריח הזכוכית | האחות וֶספֶּר | להב הירח (נזק) + פתיחת האח |
| האח הכבויה | המכבה | הסוף |

ועוד: 10 סוגי אויבים, 4 דמויות לשיחה, חנות, מזבחות שמירה, מפה, לבבות וכלי נשמה נסתרים,
שלהבת נוקמת (קסם) וריפוי בנשמה, מערכת "אפר" — השעווה שלך נשארת היכן שמתת.

## שליטה
| מקלדת | פעולה |
|---|---|
| חצים / WASD | תזוזה |
| רווח / Z | קפיצה |
| X / J | תקיפה (עם ↑ / ↓ באוויר) |
| C / Shift | זינוק |
| F הקשה / החזקה | שלהבת נוקמת / ריפוי |
| ↑ | דיבור / ישיבה |

| Esc | הפסקה |

בנייד יש ג׳ויסטיק וכפתורים על המסך, וגם שלט (Gamepad) נתמך.

## איך נוצרה האמנות
כל הגרפיקה נוצרה בקוד, ב־`tools/`:
- **דמויות, אויבים, בוסים ואביזרים** — מודלים תלת־ממדיים ב־Blender (bpy), מונפשים ומרונדרים ב־Cycles
  לגיליונות ספרייטים (`enemies3d.py`, `bosses3d.py`, `wick_model.py`, `props3d.py`, `pack.py`).
- **רקעים** — סצנות גותיות תלת־ממדיות שלמות עם ערפל נפחי וקרני אור (`bg_nave.py`, `bg_scenes.py`, `gothic.py`).
- **קרקע החדרים** — כל חדר מרונדר כתבליט תלת־ממדי עם נטיפי שעווה, טחב, גבישים ונרות (`terrain3d.py`).
- **מוזיקה וסאונד** — מסונתזים בזמן אמת ב־WebAudio (`js/audio.js`).

בנייה מחדש: `tools/build_rooms.sh`, `tools/build_chars.sh`, `tools/render_bgs.sh`, `python3 tools/props3d.py`,
ובסוף `python3 tools/build_data.py`. דורש `pip install bpy numpy opencv-python-headless pillow`.

## בדיקות
`tools/` + סקריפטי Playwright שהורצו בפיתוח: בוט BFS שבודק על פיזיקת המשחק האמיתית שכל מעבר בעולם
נגיש רק עם היכולת הנכונה (ושאין מקום להיתקע בו), ובוט "קוף" שנלחם בכל בוס בלי שגיאות.
