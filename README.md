# יהלי לוין: בריחה מהסטיקרים

משחק ארקייד מלמעלה. יהלי בורח מהחברה שרוצים להדביק לו סטיקר.
כל פגיעה מדביקה סטיקר אמיתי על המסך ומסתירה חלק משדה הראייה. חמישה סטיקרים — נפסלת.

## איך מפעילים

**המשחק חי כאן:** https://avishaicohen1112.github.io/yehali-stickers/ — אפשר גם "להתקין" אותו
למסך הבית (PWA): בדפדפן בטלפון, תפריט → "הוסף למסך הבית". זה מריץ אותו במסך מלא בלי סרגל כתובת,
וגם עובד אופליין אחרי טעינה ראשונה.

להרצה מקומית מהתיקייה: לפתוח את `index.html` בדפדפן (דאבל־קליק), או להריץ את `פתח את המשחק.bat`
אם יש בעיית שיוך קבצי `.html` במחשב (פותח ישירות ב-Edge/Chrome). לא צריך שרת, לא צריך אינטרנט.

## ניקוד

עשר נקודות לשנייה, בונוס על שדרוגים ועל סיום גל, ובעיקר **"כמעט!"** —
חמיקה ממש בקצה מעלה את הקומבו (עד ×8) ומכפילה את הבונוס.

## מסך "נפסלת"

בסיום מוגרל אחד מהכינויים: גולד · סיישל · יהלי ג׳מאלי · יהלי פיצה.

## הסטיקרים

עשרת הסטיקרים יושבים ב-`assets/stickers/`. כל אחד שחטפת פעם אחת נפתח
לצמיתות ב**אוסף הסטיקרים** בתפריט הראשי. השיא והאוסף נשמרים בדפדפן.

להחלפה או הוספה של סטיקרים: לשים קובץ בתיקייה ולעדכן את המערך `stickers`
ב-`js/config.js` (שם קובץ + הכיתוב שבתמונה).

## מבנה הקוד

```
index.html          שלד + מסכי הממשק
css/style.css       עיצוב הממשק
js/utils.js         מתמטיקה, אקראיות, אחסון מקומי
js/config.js        כל המספרים והתוכן — כאן מכווננים את המשחק
js/audio.js         סאונד מסונתז ב-WebAudio (בלי קבצי שמע)
js/input.js         מקלדת, ג׳ויסטיק מגע
js/assets.js        טעינת תמונות הסטיקרים
js/sprites.js       ציור הדמויות, החפצים והזירה
js/particles.js     חלקיקים, טקסטים מרחפים, רעידת מסך
js/entities.js      שחקן, חברה, שדרוגים, קליעים
js/game.js          לולאה ראשית, גלים, התנגשויות, HUD
```

כל הכיוונון נמצא ב-`js/config.js` — מהירויות, גלים, משך שדרוגים, ניקוד
והכיתובים של הסטיקרים.
